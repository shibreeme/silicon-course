04 / AXI

把一次读写拆成五条通道

以 CPU 给加速器配置寄存器为例。完成本课后，你能判断一拍数据何时移交，画出写数据先于写地址的合法时序，并用同一套主从 RTL 复现反压、字节写入和地址错误。

从外设配置到并行访存

在 APB 中，一次访问依次经过设置和访问阶段。DMA 向内存连续搬运数据时，地址和返回数据各有自己的等待时间。AMBA 3 引入 AXI，把地址、数据与响应拆开，使下一笔请求有机会与前一笔的数据传输重叠。AMBA 4 体系包括 AXI4、AXI4-Lite 和 AXI4-Stream，可按端点需求选择。

使用场景接口与交易边界
CPU 写加速器配置AXI4-Lite。每个地址对应一个数据拍，写完成由 B 响应确认。
DMA 从 DDR 读权重AXI4 存储映射读。一条 AR 请求描述一个突发，最终数据拍携带 RLAST。
DMA 把权重交给计算核AXI4-Stream。使用 TVALID、TREADY 和 TDATA，按应用约定用 TLAST 标出包尾。接口本身没有内存地址。

三者可在同一颗芯片中同时出现。把控制寄存器通过 AXI4-Lite 配好，由 DMA 负责在 AXI4 内存侧与 Stream 数据侧之间搬运。

连接主端与寄存器外设

下表的箭头表示载荷和 VALID 的方向。对应 READY 沿反方向连接；两端共用时钟与低有效复位。实验沿时钟上升沿同步采样复位，系统集成时需按时钟域设计复位释放。

命令 start / 地址 / 数据 → lite_master ⇄ 五条通道 ⇄ lite_regs → value[31:0]
结果 done / status / result ← 主端响应寄存器
通道方向与载荷实验端口 VALID / READY握手效果
AW 写地址主 → 从，awaddrav / ar锁存字节地址
W 写数据主 → 从，wdata、wstrbwv / wr锁存数据及每字节使能
B 写响应从 → 主，brespbv / br主端获知写结果
AR 读地址主 → 从，araddrarv / arr从端采样待读地址

仅在上升沿同时采到 VALID 和 READY 才计一笔。源端有载荷时可主动置 VALID；一旦置位，必须保持 VALID 和载荷直到握手。目的端可提前置 READY 或在看到 VALID 后置位。让两个端点同时等待对方先断言会形成死锁。

一笔写入，四次观察

  1. W 先完成握手。从端单独保存 WDATA 与 WSTRB，标记 have_w。
  2. AW 若干拍后握手。从端保存地址，标记 have_a。地址与数据也允许同拍到达。
  3. 两个标记齐备后提交写入。地址 0 对应配置寄存器；每个有效 WSTRB 位覆盖一个字节。此时从端置 BVALID。
  4. 主端拉低 BREADY 时响应必须保持。B 通道握手后，主端发出 done，软件才可消费本笔写结果。

从单拍扩展至 AXI4 突发

AxLEN 编码拍数减一，AxSIZE 编码每拍传输字节数的以 2 为底的对数。以对齐的四拍 32 位 INCR 为例，起始地址 0x0FF0，AxLEN=3，AxSIZE=2，四个地址为 FF0、FF4、FF8、FFC。读的第四个握手携带 RLAST，写的第四个携带 WLAST。写突发只有一个 B 响应。

突发不能跨越 4 KiB 地址边界。若从 0x0FF8 搬相同 16 字节，分两次 INCR，每次两拍，起始分别为 0x0FF8 与 0x1000。事务 ID 用于匹配响应并约束顺序；不同 ID 的事务可在协议允许的顺序内重排。AXI4 的 W 通道没有 WID，写数据按写地址事务顺序传输。扩展实验时应给每个未完成事务保留其长度、ID 与返回状态。

先作答，再看解释

AWVALID=1 持续三拍，AWREADY 仅最后一拍为 1，共接收几个地址？

一个。前三拍之间必须保持地址；只在二者同为 1 的上升沿采样。

收到地址后从端就能拉高 BVALID 吗？

AXI4-Lite 的写响应依赖地址与数据均已握手。只收到地址时尚无数据或字节掩码，不能确认写结果。

原值 0x11223344，写 0xAABBCCDD，WSTRB=0101，读回什么？

0x11BB33DD。使能的是第 2 与第 0 字节。掩码最低位控制 WDATA[7:0]。

读数据到达后若 RREADY 为 0，外设可直接把 RDATA 连到正在变化的计数器吗？

需要保存快照或用等效电路稳定输出。RVALID 已置位但未握手期间，RDATA 与 RRESP 必须保持。

AXI4 的 WLAST 和 Stream 的 TLAST 都表示一段结束，能直接互换吗？

WLAST 标记对应写突发的最后一拍；TLAST 的包边界由流应用约定。DMA 可能拆分同一包为多个访存突发，二者的位置可不同。

进阶实验 · AXI4 的递增突发读

把上一实验的一次寄存器读取扩展为一整个数据块。请求端在 AR 通道只提交一次起始字节地址、ARSIZE=2、ARBURST=INCR 和 ARLEN=拍数减一。响应端在每次 R 握手后将地址加 4，只在最后一拍置 RLAST。应用端的 take 可让传输随时停顿。

例如从 0x0FF0 读四拍，地址依次为 FF0、FF4、FF8、FFC；从 0x0FF4 读四拍则会跨越 4 KiB 页，命令须在发出 AR 前拒绝。本设计限定单一隐含 ID、单笔在途、对齐的 32 位 INCR 读。两端约定固定边带属性，实验不含突发写或乱序返回。

burst.sv
module burst_reader(
    input logic clk, rst_n, start,
    input logic [31:0] base, input logic [7:0] len,
    output logic busy, done, fault,
    output logic [31:0] araddr, output logic [7:0] arlen,
    output logic [2:0] arsize, output logic [1:0] arburst,
    output logic arvalid, input logic arready,
    input logic [31:0] rdata, input logic [1:0] rresp,
    input logic rvalid, rlast, output logic rready,
    input logic take, output logic valid, output logic [31:0] sample
);
    logic receiving;
    logic [7:0] remaining;
    // Exclusive byte end within the current 4 KiB page; 4096 is legal.
    wire [12:0] end_offset = {1'b0,base[11:0]} + ({5'b0,len} + 13'd1) * 13'd4;
    assign arsize=3'd2;
    assign arburst=2'b01;
    assign rready=receiving && take;
    assign valid=receiving && rvalid;
    assign sample=rdata;
    always_ff @(posedge clk) begin
        if (!rst_n) begin
            {busy,done,fault,arvalid,receiving,araddr,arlen,remaining} <= '0;
        end else begin
            done <= 0;
            if (!busy && start) begin
                fault <= 0;
                if (base[1:0]!=0 || end_offset>4096) begin
                    fault <= 1;
                    done <= 1;
                end else begin
                    busy <= 1;
                    arvalid <= 1;
                    araddr <= base;
                    arlen <= len;
                    remaining <= len;
                end
            end
            if (arvalid && arready) begin
                arvalid <= 0;
                receiving <= 1;
            end
            if (rvalid && rready) begin
                if (rresp!=0 || rlast!=(remaining==0)) fault <= 1;
                if (rlast) begin busy<=0; receiving<=0; done<=1; end
                else remaining <= remaining-1'b1;
            end
        end
    end
endmodule

// Paired responder for aligned 32-bit INCR requests. Single implicit ID.
module burst_rom(
    input logic clk, rst_n,
    input logic [31:0] araddr, input logic [7:0] arlen,
    input logic arvalid, output logic arready,
    output logic [31:0] rdata, output logic [1:0] rresp,
    output logic rvalid, rlast, input logic rready
);
    logic [31:0] address;
    logic [7:0] remaining;
    assign arready=rst_n && !rvalid;
    assign rresp=0;
    assign rdata=address ^ 32'h5aa50000;
    assign rlast=rvalid && remaining==0;
    always_ff @(posedge clk) begin
        if (!rst_n) begin rvalid<=0; address<=0; remaining<=0; end
        else if (arvalid && arready) begin
            address<=araddr;
            remaining<=arlen;
            rvalid<=1;
        end else if (rvalid && rready) begin
            if (rlast) rvalid<=0;
            else begin address<=address+4; remaining<=remaining-1'b1; end
        end
    end
endmodule
lite.sv
module lite_master(input wire clk,rst_n,start,write_cmd,
  input wire [31:0] addr,data, input wire [3:0] strobe,
  output reg busy,done, output reg [31:0] result, output reg [1:0] status,
  output reg av, wv, br, arv, rr, input wire ar,wr,bv,arr,rv,
  output reg [31:0] awaddr,wdata,araddr, output reg [3:0] wstrb,
  input wire [31:0] rdata,input wire [1:0] bresp,rresp);
  always @(posedge clk) begin
    if(!rst_n) begin
      busy<=0;done<=0;av<=0;wv<=0;br<=0;arv<=0;rr<=0;
      result<=0;status<=0;awaddr<=0;araddr<=0;wdata<=0;wstrb<=0;
    end else begin
      done<=0;
      if(start && !busy) begin
        busy<=1;
        if(write_cmd) begin
          av<=1;wv<=1;br<=1;awaddr<=addr;wdata<=data;wstrb<=strobe;
        end else begin arv<=1;rr<=1;araddr<=addr;end
      end
      if(av && ar) av<=0;
      if(wv && wr) wv<=0;
      if(arv && arr) arv<=0;
      if(br && bv) begin br<=0;busy<=0;done<=1;status<=bresp;end
      if(rr && rv) begin rr<=0;busy<=0;done<=1;result<=rdata;status<=rresp;end
    end
  end
endmodule

module lite_regs(input wire clk,rst_n,input wire av,wv,br,arv,rr,
  output wire ar,wr,arr,output reg bv,rv,
  input wire [31:0] awaddr,wdata,araddr,input wire [3:0] wstrb,
  output reg [31:0] rdata,output reg [1:0] bresp,rresp);
  reg have_a,have_w; reg [31:0] a,d,value; reg [3:0] mask;
  integer i;
  assign ar=!have_a && !bv;
  assign wr=!have_w && !bv;
  assign arr=!rv;
  always @(posedge clk) begin
    if(!rst_n) begin
      have_a<=0;have_w<=0;bv<=0;rv<=0;value<=0;rdata<=0;bresp<=0;rresp<=0;
    end else begin
      if(av && ar) begin have_a<=1;a<=awaddr;end
      if(wv && wr) begin have_w<=1;d<=wdata;mask<=wstrb;end
      if(have_a && have_w) begin
        have_a<=0;have_w<=0;bv<=1;bresp<=(a==0)?0:2;
        if(a==0) for(i=0;i<4;i=i+1)
          if(mask[i]) value[i*8+:8]<=d[i*8+:8];
      end
      if(bv && br) bv<=0;
      if(arv && arr) begin rv<=1;rresp<=(araddr==0)?0:2;rdata<=(araddr==0)?value:0;end
      if(rv && rr) rv<=0;
    end
  end
endmodule

module tb;
  bit clk; always #5 clk=~clk;
  bit rst_n,start,write_cmd;bit [31:0] addr,data;bit [3:0] strobe;
  wire busy,done;wire [31:0] result;wire [1:0] status;
  wire av,wv,br,arv,rr,ar,wr,bv,arr,rv;
  wire [31:0] awaddr,wdata,araddr,rdata;wire [3:0] wstrb;wire [1:0] bresp,rresp;
  bit ga,gw,gb,gr;wire sa,sw,sb,sr;
  assign ar=sa && ga; assign wr=sw && gw;
  assign bv=sb && gb; assign rv=sr && gr;
  lite_master m(.*);
  lite_regs s(.av(av && ga),.wv(wv && gw),.ar(sa),.wr(sw),.bv(sb),
    .br(br && gb),.rv(sr),.rr(rr && gr),.*);
  task tick; @(negedge clk); endtask
  task command(input bit we,input [31:0] address,payload,input [3:0] mask);
    write_cmd=we;addr=address;data=payload;strobe=mask;start=1;tick();start=0;
  endtask
  task testwrite(input bit addr_first,input [31:0] address,payload,input [3:0] mask,input [1:0] response);
    ga=addr_first;gw=!addr_first;gb=0;
    command(1,address,payload,mask);
    repeat(3) tick();
    if(av!==!addr_first || wv!==addr_first || sb!==0) $fatal(1,"independence");
    ga=1;gw=1;repeat(4) tick();
    repeat(3) begin if(sb!==1 || bresp!==response || done!==0) $fatal(1,"B stall");tick();end
    gb=1;tick();if(done!==1 || status!==response) $fatal(1,"B completion");
  endtask
  task testread(input [31:0] address,expected,input [1:0] response);
    gr=0;command(0,address,0,0);tick();
    repeat(3) begin if(sr!==1 || rdata!==expected || rresp!==response) $fatal(1,"R stall");tick();end
    gr=1;tick();if(done!==1 || result!==expected || status!==response) $fatal(1,"R completion");
  endtask
  initial begin
    tick();rst_n=1;testread(0,0,0);
    testwrite(1,0,'h11223344,15,0); testwrite(0,0,'haabbccdd,5,0);
    testread(0,'h11bb33dd,0);testwrite(0,4,0,15,2);testread(4,0,2);
    testread(0,'h11bb33dd,0);$display("PASS AXI-Lite: split writes, stalls, strobes, errors");$finish;
  end
  initial #3000 $fatal(1,"timeout");
endmodule
tb_burst.sv
module tb_burst;
    bit clk; always #5 clk=~clk;
    logic rst_n,start,busy,done,fault,arvalid,arready,rvalid,rlast,rready,take,valid;
    logic [31:0] base,araddr,rdata,sample;
    logic [7:0] len, arlen;
    logic [2:0] arsize;
    logic [1:0] arburst,rresp;
    burst_reader manager(.*);
    burst_rom responder(.*);
    integer addresses;
    always @(posedge clk) if (rst_n && arvalid && arready) addresses++;
    task check(input logic [31:0] origin,input integer count,input bit legal);
        integer seen, before_count;
        @(negedge clk); before_count=addresses;
        start=1; base=origin; len=count-1; take=0;
        @(negedge clk); start=0;
        if (!legal) begin
            if ({done,fault,busy,arvalid} !== 4'b1100) $fatal(1,"bad request accepted");
        end else begin
            if ({arvalid,arburst,arsize} !== 6'b101010 || araddr !== origin || arlen !== len)
                $fatal(1,"address descriptor");
            seen=0;
            while (seen<count) begin
                while(!valid) @(negedge clk);
                repeat(2) begin
                    if (valid!==1 || sample!==((origin+4*seen)^32'h5aa50000) ||
                        rlast!==(seen==count-1)) $fatal(1,"data or last");
                    @(negedge clk);
                end
                take=1; @(negedge clk); take=0; seen++;
            end
            if (!done || fault || addresses!=before_count+1) $fatal(1,"completion");
        end
    endtask
    initial begin
        rst_n=0; start=0; take=0;
        repeat(2) @(negedge clk); rst_n=1;
        check('h100,1,1); check('hff0,4,1); check('hff4,4,0);
        check('h002,1,0); check('h4000,256,1);
        $display("PASS AXI4 INCR read: 1/4/256 beats, stalls, alignment and 4KiB boundary");
        $finish;
    end
    initial #20000 $fatal(1,"timeout");
endmodule
