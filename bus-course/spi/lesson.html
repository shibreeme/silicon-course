SPI / SERIAL PERIPHERAL INTERFACE

用八个时钟，交换两个字节

设想一个控制器向外设发送 0x96，同时读回状态 0x53。先确定谁生成时钟，再约定首位何时有效，最后用波形证明两个字节各自准确到达。

从移位寄存器到板级总线

SPI 源于 Motorola 微控制器的同步外设互连。把两端移位寄存器首尾相接，每一次采样交换一位，八次就能双向传输两个字节。增加独立片选后，多个外设可共用时钟和数据线。现代串行闪存又发展出双线、四线数据阶段，增加引脚并行度的同时引入命令、地址、方向切换与等待周期。

经典四线 SPI 描述传输节拍。读取哪个寄存器、命令占几位、两字节之间能否释放片选，由具体器件手册规定。以 SAM D21 的 SERCOM 为工程对照，先核对时钟模式，再检查位序和实际 SCK 频率。Microchip SAM D21 数据手册

先找空闲电平，再找采样沿

CPOL 决定空闲时 SCK 的电平。将离开空闲电平的边沿称为第一沿，返回的边沿称为第二沿。CPHA 为 0 时第一沿采样，因此第一个数据位必须在第一沿到来前就稳定。

模式CPOL / CPHA采样准备下一位
00 / 0上升沿下降沿
10 / 1下降沿上升沿
21 / 0下降沿上升沿
31 / 1上升沿下降沿

Microchip SPI 模式定义

从管脚连到模块

应用 ── start, tx ──▶ controller ── cs_n, sck, mosi ──▶ peripheral ◀── reply
应用 ◀── done, rx ─── controller ◀──────── miso ─────── peripheral ──▶ received
信号契约
clk / rst控制端系统时钟与同步高有效复位。复位使 CS 回高、SCK 回低。
start / busy / done空闲时接受 start 和 tx；发起方给一个时钟的脉冲。busy 期间忽略新请求。done 高一拍，此时 rx 可读。
cs_n / sck控制端驱动。cs_n 低包围一帧；本例每个系统时钟切换一次 SCK，频率等于 clk 的一半。
mosi / miso分别从控制端、外设送出。两端共地，未选中的外设释放 MISO。硅片顶层用输出使能控制 pad。
reply / received外设回复字节须在片选前准备好并保持到帧结束。received 在第八个采样沿后完整；跨入另一时钟域时需要握手或异步 FIFO。

手工解码模式 0

上升沿序号    1 2 3 4 5 6 7 8
MOSI (0x96)   1 0 0 1 0 1 1 0
MISO (0x53)   0 1 0 1 0 0 1 1

片选拉低时预装 bit 7。随后每个下降沿准备下一位，两端在下一上升沿采样。最后一个下降沿让 SCK 回到空闲，控制器再释放片选。假设 clk 为 20 MHz，则八个 SCK 周期占 0.8 µs，完整帧还包含片选建立、保持与帧间空闲。

概念自测

接收端要读数据，为什么控制端仍要发送字节？

控制端必须生成时钟。发送填充字节可让外设移出返回值，填充值和等候拍数应按器件手册选择。

两端都选上升沿采样，模式就一致吗？

模式 0 和模式 3 都在上升沿采样，但空闲电平与起始相位不同。请先画出片选后第一个边沿，再检查首位的建立时间。

八次采样都到了，仍然读回全 1，该检查哪里？

先检查 CS 是否选对以及 MISO 驱动是否使能。未选中器件可能把返回线置于高阻；有上拉的板子会表现为全 1。再核对读命令、响应延迟和引脚复用。

频率加倍后偶尔错一位，如何判断能否收敛？

对于本例 MISO 半周期路径，将控制器时钟输出延迟、板级往返、外设输出延迟及接收器建立时间相加，比较半周期预算。实现时约束生成时钟和 I/O 时序，分别检查建立与保持时间。

逐行阅读源码

先读两端的接口声明，再展开测试台，沿模块实例上的连线回到每个信号的驱动端。

spi.sv
// Mode 0, eight bits, MSB first. One byte per asserted CS.
module spi_controller(input logic clk, rst, start, input logic [7:0] tx,
    input logic miso, output logic sck, cs_n, mosi, busy, done, output logic [7:0] rx);
    logic [7:0] transmit, receive;
    logic [2:0] index;
    logic finish_frame;
    always_ff @(posedge clk) begin
        if (rst) begin
            sck <= 0; cs_n <= 1; busy <= 0; done <= 0;
            mosi <= 0; rx <= 0; finish_frame <= 0;
        end else begin
            done <= 0;
            if (!busy && start) begin
                transmit <= tx; receive <= 0; index <= 7; mosi <= tx[7];
                cs_n <= 0; busy <= 1;
            end else if (busy && finish_frame) begin
                cs_n <= 1; busy <= 0; done <= 1; rx <= receive; finish_frame <= 0;
            end else if (busy && !sck) begin
                sck <= 1; receive <= {receive[6:0],miso};
            end else if (busy) begin
                sck <= 0;
                if (index == 0) finish_frame <= 1;
                else begin index <= index-1'b1; mosi <= transmit[index-1'b1]; end
            end
        end
    end
endmodule

// Keep reply stable from before CS assertion until CS deassertion.
module spi_peripheral(input logic sck, cs_n, mosi, input logic [7:0] reply,
    output wire miso, output logic [7:0] received);
    logic [2:0] index;
    always_ff @(negedge sck or posedge cs_n)
        if (cs_n) index <= 7;
        else index <= index-1'b1;
    assign miso = cs_n ? 1'bz : reply[index];
    always_ff @(posedge sck)
        if (!cs_n) received <= {received[6:0],mosi};
endmodule
tb_spi.sv
module tb_spi;
    bit clk;
    always #5 clk = ~clk;
    logic rst=1,start=0;
    logic [7:0] tx,reply;
    wire [7:0] rx,received;
    wire miso,mosi,sck,cs_n,busy,done;
    spi_controller controller(.*);
    spi_peripheral peripheral(.*);
    integer edges;
    always @(posedge sck) if (!cs_n) begin
        if (mosi !== tx[7-edges] || miso !== reply[7-edges]) $fatal(1,"wire order");
        edges = edges+1;
    end
    initial begin
        repeat(2) @(negedge clk);
        rst=0;
        for(integer n=0;n<256;n=n+1) begin
            tx=n; reply=8'h5b ^ n; edges=0; start=1;
            @(negedge clk); start=0;
            wait(done); @(negedge clk);
            if(edges!=8 || rx!==reply || received!==tx || sck!==0 ||
               cs_n!==1 || miso!==1'bz || busy!==0) $fatal(1,"frame mismatch");
        end
        $display("PASS: 256 full-duplex frames"); $finish;
    end
    initial #60000 $fatal(1,"timeout");
endmodule
