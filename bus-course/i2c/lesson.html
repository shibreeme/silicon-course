板级互连 / I²C

两根线，多个目标

在地址为 0x48 的目标上写入 0xA5。跟踪同一笔事务，从上拉电阻的作用一路读到接收寄存器的更新沿。

01　发展与原理

Philips 在 1982 年发布 I²C，为同一块板上的控制芯片和低速外设提供双线接口。共享数据线减少引脚，地址字段选择设备。标准模式上限 100 kbit/s，快速模式 400 kbit/s，Fm+ 达 1 Mbit/s。提速时要重新检查线上电容、上升时间和器件灌电流能力。

在常规开漏模式，发送 0 时驱动器拉低线路，发送 1 时释放。上拉电阻给总线电容充电才使电平升高。多个驱动器中任意一个拉低，所有输入都读到 0。用逻辑分析仪检查边沿时序，用示波器检查上升时间。

03　逐位拆解一次写事务

START │ 1001000 0 │ 0 │ 10100101 │ 0 │ STOP
         地址   写   ACK    数据     ACK

空闲时两线高。SCL 高时 SDA 由高变低构成 START。控制器在 SCL 低电平准备下一位，高电平保持稳定；最高位先发。地址 0x48 左移并补写方向位得到线上首字节 0x90。第九个时钟由控制器提供，但数据线由控制器释放，目标可拉低确认。

控制器采样 ACK 后继续发送 0xA5。目标在第八个上升沿拼出完整字节，在应答尾部提交。最后控制器先令 SDA 保持低，释放 SCL，再释放 SDA，形成 STOP。若首字节收到 NACK，本实验直接发 STOP。

04　先判断，再对照答案

一次成功的单字节写有多少个数据与应答时钟？

两个八位字节各附一次 ACK，共 18 个。START、STOP 按 SDA 在 SCL 高时的变化识别。分析仪按帧解码时要将起止边沿与数据位区分开。

地址值写成 0x90，为什么设备可能不响应？

核的接口收七位地址；0x90 已包含方向位，传入该数会被截断并再次拼接方向。先明确软件接口接受七位地址还是线上首字节。

读寄存器时为什么会遇到重复 START 和末字节 NACK？

典型顺序是写方向送寄存器指针、重复 START、读方向重新寻址，再由目标发送数据。控制器接收最后一个字节后用 NACK 通知发送方结束，然后发 STOP。具体指针语义取决于器件手册。

怎样将这个写核扩展到时钟拉伸和多控制器？

释放 SCL 后回读实际线电平，确认高电平后再采样。多控制器发送高位时还须检查 SDA，若读回低则退出仲裁；设计中还需总线空闲检测、超时恢复与协议时序验证。

05　端到端 RTL 与自检

实现范围为单控制器、七位寻址、每事务写一个字节。两端按系统时钟运行。这里用理想上拉和过采样，未建模 RC 波形、毛刺滤波或真实器件最小脉宽。教学核不实现读、多控制器仲裁、时钟拉伸。

i2c.sv
module i2c_writer(input wire clk, rst, tick, start,
 input wire [6:0] address, input wire [7:0] data, input wire sda,
 output reg scl_low, sda_low, busy, done, nack);
 localparam IDLE=0, START=1, LOW=2, SETUP=3, HIGH=4, SAMPLE=5, STOP0=6, STOP1=7, STOP2=8, STOP3=9;
 reg [3:0] state, bit_no;
 reg [7:0] tx, payload;
 reg data_phase;
 always @(posedge clk) begin
   if(rst) begin state<=IDLE; busy<=0; done<=0; nack<=0; scl_low<=0; sda_low<=0; end
   else begin
     done<=0;
     if(state==IDLE && start) begin
       tx<={address,1'b0}; payload<=data; bit_no<=0; data_phase<=0;
       state<=START; busy<=1; nack<=0;
     end else if(tick) case(state)
       START: begin sda_low<=1; state<=LOW; end
       LOW: begin scl_low<=1; state<=SETUP; end
       SETUP: begin sda_low <= bit_no==8 ? 0 : !tx[7]; state<=HIGH; end
       HIGH: begin scl_low<=0; state<=SAMPLE; end
       SAMPLE: begin
         state<=LOW;
         if(bit_no<8) begin tx<=tx<<1; bit_no<=bit_no+1'b1; end
         else if(sda || data_phase) begin nack<=sda; state<=STOP0; end
         else begin tx<=payload; bit_no<=0; data_phase<=1; end
       end
       STOP0: begin scl_low<=1; state<=STOP1; end
       STOP1: begin sda_low<=1; state<=STOP2; end
       STOP2: begin scl_low<=0; state<=STOP3; end
       STOP3: begin sda_low<=0; busy<=0; done<=1; state<=IDLE; end
       default: ;
     endcase
   end
 end
endmodule

module i2c_sink #(parameter [6:0] ADDRESS=7'h48)
 (input wire clk,rst,scl,sda, output reg sda_low, written, output reg [7:0] value);
 reg [2:0] cs, ds;
 reg [7:0] shift;
 reg [3:0] count;
 reg active, selected, payload;
 wire rise=cs[1] && !cs[2], fall=!cs[1] && cs[2];
 always @(posedge clk) begin
   if(rst) begin cs<=7; ds<=7; active<=0; written<=0; value<=0; sda_low<=0;
     count<=0; selected<=0; payload<=0; shift<=0; end
   else begin
     cs<={cs[1:0],scl}; ds<={ds[1:0],sda}; written<=0;
     if(cs[1] && ds[2] && !ds[1]) begin active<=1; count<=0; payload<=0; selected<=0; sda_low<=0; end
     else if(cs[1] && !ds[2] && ds[1]) begin active<=0; sda_low<=0; end
     else if(active) begin
       if(rise && count<8) begin
         shift<={shift[6:0],ds[1]}; count<=count+1'b1;
         if(count==7 && !payload) selected<=({shift[6:0],ds[1]}=={ADDRESS,1'b0});
       end else if(fall && count==8) begin sda_low<=selected; count<=9; end
       else if(fall && count==9) begin
         sda_low<=0; count<=0;
         if(payload && selected) begin value<=shift; written<=1; end
         active<=selected && !payload; payload<=1;
       end
     end
   end
 end
endmodule
tb.sv
module tb;
 bit clk=0; always #5 clk=!clk;
 bit rst=1,start=0; reg [6:0] addr; reg [7:0] data;
 reg [3:0] divider=0; always @(posedge clk) divider<=divider+1'b1;
 wire scl_low,md,sd,busy,done,nack,written;wire [7:0] value;
 tri1 scl,sda;
 assign scl=scl_low?1'b0:1'bz;
 assign sda=md?1'b0:1'bz;
 assign sda=sd?1'b0:1'bz;
 i2c_writer writer(clk,rst,&divider,start,addr,data,sda,scl_low,md,busy,done,nack);
 i2c_sink sink(clk,rst,scl,sda,sd,written,value);
 integer writes=0;
 always @(posedge clk) if(written) writes<=writes+1;
 task send(input [6:0] a,input [7:0] d,input bit reject);
 integer before_count;
 begin
   before_count=writes; @(negedge clk);addr=a;data=d;start=1;
   @(negedge clk);start=0;wait(done);@(negedge clk);
   if(nack!==reject || writes!=before_count+!reject || (!reject && value!==d) || sda!==1 || scl!==1)
     $fatal(1,"write %h %h",a,d);
 end endtask
 initial begin repeat(5) @(negedge clk);rst=0;
 send('h48,'ha5,0);send('h49,'h12,1);send('h48,'h00,0);send('h48,'hff,0);
 $display("PASS: I2C three writes and address NACK");$finish; end
 initial #1000000 $fatal(1,"timeout");
endmodule
