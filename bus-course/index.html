DESIGN REVIEW

沿一笔访问选择协议

设计需求首要约束总线与工程判断
多个板级温度传感器引脚少，共享线路I²C 按地址选设备，核对地址冲突、上拉与总线电容。
读取外部串行 Flash双向移位、器件命令SPI 由片选定帧，按器件手册核对模式、地址宽度和空周期。
CPU 配置加速器阈值少量寄存器，有副作用APB 简化端点；仅在完成拍更新配置。
DMA 成块搬运张量内存带宽与反压AXI4 用突发摊薄地址开销；控制寄存器可另接 AXI4-Lite。

把四课串成一个系统

设想一个传感器采集 SoC。CPU 经 AXI 互连和 AXI-to-APB 桥配置 I²C 或 SPI 控制器；控制器在芯片引脚上完成串行传输，把结果放入 FIFO。批量采样时，再由 DMA 经 AXI4 写入内存。画出这条路径，并在每一段标注时钟域、完成条件和错误如何上报。四个分课分别验证各自的端点，这张系统图用于最后的集成设计练习。
